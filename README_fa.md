# 🍲 FridgeChef

**برنامه‌ریزی غذایی یک هفته‌ای در چند دقیقه — با هوش مصنوعی یا بدون آن.**

فریباف یک اپلیکیشن وب برای برنامه‌ریزی غذایی هفتگی است. چند سؤال را پاسخ دهید — تعداد نفرات، ترجیحات غذایی، بودجه، منطقه — تا یک برنامهٔ کامل ۷ روزه با صبحانه، ناهار و شام برای هر روز، به‌همراه فهرست خرید خودکار، ساخته شود. با کلید API، یک مدل زبانی برنامه را متناسب با ترجیحات شما می‌نویسد؛ بدون کلید، تولیدکنندهٔ دموی داخلی از یک مجموعهٔ دستورپخت انتخاب‌شده استفاده می‌کند، بنابراین اپلیکیشن کاملاً آفلاین هم کار می‌کند.

رابط کاربری به فارسی است و کاملاً راست‌به‌چپ (RTL) است.

![نمای برنامهٔ هفتگی](./public/screenshot.png)

## ✨ ویژگی‌ها

- **ویزارد ۴ مرحله‌ای** — خانوار و رژیم غذایی → بودجه → منطقه و سبک → برنامه، با مقادیر پیش‌فرض معقول در هر مرحله
- **برنامهٔ هوشمند یا دمو** — سوئیچ بین حالت هوشمند (تولیدشده با LLM) و دمو؛ اگر هیچ provider-i پیکربندی نشده باشد یا درخواست ناموفق باشد، اپ به‌صورت خودکار به تولیدکنندهٔ دمو برمی‌گردد تا همیشه برنامه داشته باشید
- **ویرایشگر تعاملی برنامه** — تعویض هر وعده با دستورپخت دیگر، افزودن یادداشت برای هر روز، و ذخیرهٔ برنامه
- **فهرست خرید** — از برنامهٔ ذخیره‌شده جمع‌آوری می‌شود، با تیک‌زنی و تولید خودکار برای هر روز
- **کتابخانهٔ دستورپخت** — ۶۸ دستورپخت دمو (۱۰ دستهٔ کلاسیک، ۲۰ فصلی) با فیلتر دسته و جست‌وجو
- **آگاه از منطقه** — با انتخاب شهر و سبک منطقه‌ای (تهران، اصفهان، شیراز، تبریز، کرمان، مشهد، اهواز) آشپزی شکل می‌گیرد
- **کاملاً ماندگار در مرورگر** — برنامه‌ها و تنظیمات در `localStorage` ذخیره می‌شوند؛ بدون حساب، بدون پایگاه داده
- **تنظیمات** — شهر، سبک منطقه‌ای، واحد پول، به‌همراه وارد/خروجی داده و بازنشانی
- **واکنش‌گرا و دسترس‌پذیر** — چیدمان RTL، نشانه‌گذاری معنایی، انیمیشن روان

## 🚀 شروع سریع

```bash
# ۱. کلون
git clone <آدرس-رپویاری> freebuff

# ۲. نصب
npm install

# ۳. (اختیاری) پیکربندی provider هوش مصنوعی
cp .env.example .env.local
# در .env.local حداقل یک کلید وارد کنید — بخش "Providerهای هوش مصنوعی" را ببینید

# ۴. اجرای سرور توسعه
npm run dev
```

بروید به [http://localhost:3000](http://localhost:3000).

بدون هیچ کلیدی، اپ در **حالت دمو** کار می‌کند: تولیدکننده از مجموعهٔ دستورپخت داخلی استفاده می‌کند. برای امتحان برنامهٔ هوشمند، یک کلید اضافه کنید و در صفحهٔ برنامه‌ریز حالت را روی «هوشمند» بگذارید.

## 🤖 Providerهای هوش مصنوعی

برنامه‌های هوشمند از یک route واحد، `POST /api/plan` تولید می‌شوند. سرور Providerها را **به این ترتیب** امتحان می‌کند و از اولی که کلید دارد استفاده می‌کند:

| # | Provider   | متغیر محیطی        | توضیح                                              |
| - | ---------- | ------------------- | ---------------------------------------------------- |
| ۱ | Groq       | `GROQ_API_KEY`      | توصیه‌شده — سریع و با پلن رایگان سخاوتمندانه       |
| ۲ | OpenRouter | `OPENROUTER_API_KEY` | یک کلید برای بیش از ۴۰۰ مدل                  |
| ۳ | Mistral    | `MISTRAL_API_KEY`   |                                                  |
| ۴ | DeepSeek   | `DEEPSEEK_API_KEY`  |                                                  |
| ۵ | GLM        | `GLM_API_KEY`       | Zhipu BigModel                                     |
| ۶ | OpenAI     | `OPENAI_API_KEY`    | GPT-4o-mini                                        |
| ۷ | Gemini     | `GEMINI_API_KEY`    | Gemini 2.0 Flash                                   |

نکات کلیدی:

- **فقط یک کلید کافی است.** آن را در `.env.local` (نمونه در `.env.example`) تنظیم کنید و سرور توسعه را دوباره راه بیندازید.
- **بدون کلید = حالت دمو.** اگر هیچ‌کدام پیکربندی نباشد، route یک برنامه از تولیدکنندهٔ داخلی برمی‌گرداند و در رابط کاربری نشان حالت دمو دیده می‌شود.
- **تجزیهٔ امن.** پاسخ باید با یک اسکیمای Zod سخت‌گیرانه مطابقت داشته باشد؛ هر شکستی به مجموعهٔ دمو برمی‌گردد تا دادهٔ خراب به رابط کاربری نرسد.
- **بدون استریمینگ و بدون AI SDK.** route از `fetch` مستقیم به endpoint `chat/completions` با JSON mode استفاده می‌کند — عمداً کوچک و بدون وابستگی اضافی.
- پرومپت و خروجی به فارسی هستند (روزها، غذاها، مواد اولیه با مقدار و قیمت، هزینهٔ کل هر روز).
