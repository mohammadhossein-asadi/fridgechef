## 📖 این پروژه چیست

**FridgeChef** یک برنامه‌ی تحت وب برای برنامه‌ریزی هوشمند غذای هفتگی است.
این ابزار با در نظر گرفتن نیازهای کاربران فارسی‌زبان، لیست خرید، منوی غذایی روزانه
و **تقویم جلالی** را به‌صورت کامل (راست‌به‌چپ) پشتیبانی می‌کند.

### ✨ ویژگی‌های کلیدی

- **۴ مرحله برای ساخت برنامه:**
  - انتخاب **سلات‌های غذایی** (صبحانه، ناهار، شام، میان‌وعده) و تعداد **روزها**
  - فیلتر بر اساس **بودجه**، **تعداد نفرات**، **غذاهای موردعلاقه / بی‌علاقه** و **حساسیت‌ها**
  - انتخاب بین **دستیار هوشمند** یا **برنامه‌ریز جایگزین**
  - مشاهده‌ی **لیست خرید** با دسته‌بندی و **میانگین هزینه‌ی روزانه**
- **موتور جایگزین** (`src/lib/planner.ts`) که بدون بک‌اند هوش مصنوعی هم منو می‌سازد.
- **دیتابیس ۷۰+ recipe** فارسی (`src/lib/ingredients.ts`) با دسته‌بندی، مواد لازم و قیمت.
- **پشتیبانی کامل **RTL / LTR** با نرمال‌سازی یه و کاف فارسی/عربی و **تقویم جلالی**.
- **Dark/Light** کامل و **طراحی مدرن و روان** با **Tailwind v4**.

│  ├─ units.ts                    # تبدیل واحدهای وزن و حجم
│  ├─ budget.ts                   # محاسبه‌ی قیمت بر اساس دسته و وزن
│  ├─ dates.ts                    # تبدیل تاریخ میلادی → جلالی
│  ├─ format.ts                   # قالب‌بندی عدد / تاریخ / هزینه
│  ├─ ingredients.ts              # دیتابیس ۷۰+ recipe + مواد لازم و قیمت
│  └─ store.ts                    # state مدیریت‌شده با Zustand
└─ ai/
   ├─ provider.ts                # انتخاب بین OpenAI و حالت Demo

## ⚡ نصب و اجرا

```bash
# ۱. نصب پکج‌ها
pnpm install
# یا npm install / yarn install

# ۲. کپی فایل تنظیمات
cp .env.example .env.local

# ۳. (اختیاری) تنظیم بک‌اند هوش مصنوعی در .env.local
# AI_PROVIDER=openai
# AI_API_KEY=sk-xxxx
# AI_MODEL=gpt-4o-mini
# AI_BASE_URL=https://api.openai.com/v1

# ۴. اجرا در حالت توسعه
pnpm dev   # http://localhost:3000
```

> برای اجرای بدون بک‌اند، فقط فایل `.env.local` را خالی بگذارید تا برنامه در
> **حالت Demo** (با داده‌های نمونه‌ی فارسی) اجرا شود.

## 🎯 نحوه‌ی کار

1. **مرحله‌ی ۱ — سلات‌ها و روزها:** تعداد هر سالت غذایی و تعداد روزها را انتخاب کنید.
2. **مرحله‌ی ۲ — فیلترها:** بودجه، تعداد نفرات، غذاهای موردعلاقه/بی‌علاقه و حساسیت‌ها.
3. **مرحله‌ی ۳ — موتور:** بین **دستیار هوشمند** (API) یا **برنامه‌ریز داخلی** انتخاب کنید.
4. **مرحله‌ی ۴ — نتیجه:** منوی غذایی هفتگی + لیست خرید دسته‌بندی‌شده + میانگین هزینه‌ی روزانه.

## 📐 قراردادهای داده

```typescript
type MealSlot = 'breakfast' | 'lunch' | 'dinner' | 'snack';

interface MenuData {
  days: MenuDay[];
  shoppingList: ShoppingItem[];
  budget: {
    dailyAverageCost: number;
    dailyBudget: number;
    servingCount: number;
  };
}
```

تمامی ورودی‌ها و خروجی‌ها با **Zod** اعتبارسنجی می‌شوند (`src/lib/schemas.ts`)
و واحدهای وزن و حجم با `src/lib/units.ts` و قیمت‌ها با `src/lib/budget.ts` محاسبه می‌شوند.

---

## 🌐 پشتیبانی از زبان و منطقه

- **راست‌به‌چپ (RTL) کامل** برای فارسی + **چپ‌به‌راست (LTR)** برای انگلیسی.
- **نرمال‌سازی یه/کاف** (YEH/KAF) برای متن فارسی و عربی.
- **تقویم جلالی** با `jalali-js` (تبدیل تاریخ‌ها در `src/lib/dates.ts`).
- **قالب‌بندی عدد و هزینه** مناسب با `src/lib/format.ts`.

---

## 🤖 تأمین‌کننده‌ی هوش مصنوعی

برنامه بین دو حالت انتخاب می‌کند (`src/lib/ai/provider.ts`):

- **OpenAI-compatible:** با تنظیم `AI_PROVIDER=openai` و کلید/API/ماژول در `.env.local`.
- **Demo:** اگر هیچ متغیری تنظیم نشده باشد، از داده‌های نمونه‌ی فارسی استفاده می‌شود.
