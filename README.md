# 🍲 Sofreh (سفره)

**Plan a week of food in minutes — Persian meal planning, with or without AI.**

Sofreh (سفره) is a weekly meal-planning web app. Answer a few questions — how many people, diet preferences, budget, region — and it builds a complete 7-day plan with breakfast, lunch and dinner for every day, plus an automatic shopping list. With an API key, an LLM writes the plan around your preferences; without one, a built-in demo generator fills in from a hand-picked recipe pool, so the app works fully offline.

The interface is in Persian with full RTL support.

![Weekly plan view](./public/screenshot.png)

## ✨ Features

- **4-step planning wizard** — household & diet → budget → region & style → plan, with sensible defaults at every step
- **AI or demo plans** — toggle between smart (LLM-generated) and demo mode; if no provider is configured or a request fails, the app silently falls back to the demo generator so you always get a plan
- **Interactive plan editor** — swap any meal for a different recipe, add notes per day, then save your plan
- **Shopping list** — aggregated from the saved plan with checkboxes, auto-generated per day
- **Recipe library** — 68 demo recipes (10 classic categories, 20 seasonal) with category and search filters
- **Region-aware** — pick a city and regional style (Tehran, Isfahan, Shiraz, Tabriz, Kerman, Mashhad, Ahvaz) to shape the cuisine
- **Fully client-persistent** — plans and settings are stored in `localStorage`; no account, no backend database
- **Settings** — city, regional style, currency, plus data import/export and reset
- **Responsive & accessible** — RTL layout, semantic markup, smooth motion

## 🧱 Tech Stack

| Layer       | Tech                                                        |
| ----------- | ----------------------------------------------------------- |
| Framework   | [Next.js](https://nextjs.org) 15 (App Router)               |
| Language    | [TypeScript](https://www.typescriptlang.org) (strict)       |
| Styling     | [Tailwind CSS](https://tailwindcss.com) 4                   |
| Animation   | [Framer Motion](https://www.framer.com/motion)              |
| State       | [Zustand](https://zustand.docs.pmnd.rs) 5 (persisted to `localStorage`) |

There is no database and no server-side state — everything lives in your browser.

## 🚀 Quick Start

```bash
# 1. Clone

# 2. Install
npm install

# 3. (Optional) Configure an AI provider
cp .env.example .env.local
# edit .env.local and set at least one key — see "AI providers" below

# 4. Run
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

With no keys set, the app runs in **demo mode**: the plan generator uses its built-in recipe pool. To try AI plans, add one key and switch the mode to «هوشمند» in the planner.

## 🤖 AI Providers

AI plans are generated by a single `POST /api/plan` route. The server tries the providers **in this order** and uses the first one with a key configured:

| #  | Provider   | Env var            | Notes                                              |
| -- | ---------- | ------------------ | -------------------------------------------------- |
| 1  | Groq       | `GROQ_API_KEY`     | Recommended — fast and has a generous free tier    |
| 2  | OpenRouter | `OPENROUTER_API_KEY` | One key for 400+ models                     |
| 3  | Mistral    | `MISTRAL_API_KEY`  |                                                    |
| 4  | DeepSeek   | `DEEPSEEK_API_KEY` |                                                    |
| 5  | GLM        | `GLM_API_KEY`      | Zhipu BigModel                                     |
| 6  | OpenAI     | `OPENAI_API_KEY`   | GPT-4o-mini                                        |
| 7  | Gemini     | `GEMINI_API_KEY`   | Gemini 2.0 Flash                                   |

Key points:

- **You only need one key.** Set it in `.env.local` (see `.env.example`) and restart the dev server.
- **No key = demo mode.** If nothing is configured, the API route returns a plan from the built-in generator and the UI shows a demo-mode badge.
- **Fail-safe parsing.** The response must match a strict Zod schema; any parse failure falls back to the demo pool so the UI never receives broken data.
- **No streaming, no AI SDK.** The route uses a plain `fetch` to the provider's `chat/completions` endpoint with JSON mode — small and dependency-free on purpose.
- The prompt and output are in Persian (days, dishes, ingredients with quantities and prices, total cost per day).
